# Aula de práctica UNACH

Aula virtual ligera construida en HTML, CSS y JavaScript, sin bibliotecas ni imágenes externas. Incluye un simulacro completo de 80 preguntas y cuatro prácticas de 20 preguntas por área. El banco sigue, pregunta por pregunta, los tipos de ejercicios del PDF «Simulador 2026-1S Revisión del intento Unach»; cambia datos, nombres y redacción. Las tablas, matrices, códigos y opciones se muestran como HTML adaptable.

Cada modalidad conserva su intento y cronómetro por separado en el navegador, de modo que se puede cambiar de área o pasar al simulacro completo y luego continuar. Como se reemplazó el banco anterior, los intentos antiguos no se trasladan a estas preguntas nuevas.

La página ofrece navegación entre preguntas, resultados por área y una revisión plegable de las cuatro opciones con filtros por estado y área. Incluye progreso local, modo claro/oscuro y una vista adaptable a móvil. No requiere registro ni envía datos personales.

## Publicar en GitHub Pages

1. Sube `index.html` al directorio raíz de un repositorio de GitHub.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Guarda y abre la URL publicada por GitHub.

El banco es material independiente de práctica, adaptado a partir del PDF aportado. No es oficial ni reproduce literalmente sus preguntas.
